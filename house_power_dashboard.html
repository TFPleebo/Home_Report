Outdoor Temperature Scenario

i
Real data check: on 320 real cooling-season days, humidity had a statistically significant effect on electric cost even after accounting for temperature (p<0.001) — a muggy 70°F day genuinely costs more to cool than a dry 70°F day. This home's actual humidity ranged 43%-96%, averaging ~72%. Effect only applies above the balance point, where the AC is doing real work.

The chart below plots cost across temperatures — the dashed line marks the current balance point (refit nightly), with cooling costs rising to its right and heating costs to its left.

1b. EGO battery-powered devices

i
These EGO tools plug straight into an EGO battery — no inverter needed, and they can't run on the EcoFlow batteries. Each device uses its own battery, independent of whatever's powering the EGO Inverter above, so you can run more than one at once if you own enough batteries.

2. Solar charging (optional)

i
Assumes ~65% real-world efficiency vs. the 400W rating (panel angle, clouds, charge-controller loss) — not the nameplate spec. This adds charge back in during the day rather than a one-time boost, so it matters most for outages longer than 24 hours.

3. Loads you want to run

i
Set where each load actually is — the runtime by station below only counts a load against battery capacity that's stationed in the same place.

Estimated runtime by station

i
Each station can only run on the battery capacity actually stationed there — a fridge in the kitchen can't draw on a battery upstairs. This is the realistic view; the combined totals above assume everything could share power, which it can't. Also assumes ~10% inverter/conversion loss plus a fixed 15W the power station itself burns while switched on (measured against the real 9/19/2026 outage \u2014 that overhead matters most for small loads like a lone fridge). Beyond that — real-world runtime varies with cycling, temperature, and inverter idle draw (your March outage test showed the fridge alone using less than the flat estimate).
